C callgraph contract coverage includes AWS-LC 1.5 through 5.x: ML-KEM and ML-DSA key creation from a NID through the KEM and PQDSA EVP_PKEY APIs, key type and consistency checks, deterministic key generation and encapsulation, the ML-DSA signature context string, and the TLS key-exchange group identifiers configured through SSL_CTX_set1_group_ids and SSL_set1_group_ids. The hybrid group negotiated by the handshake, such as X25519MLKEM768, is reported from SSL_get_group_id and SSL_get_group_name, separately from the configured group list. Rust callgraph contract coverage includes the post-quantum API of aws-lc-rs 1.6 through 1.18: ML-KEM encapsulation and decapsulation keys, and ML-DSA key pair generation, loading, signing and verification in both the unstable (1.13 to 1.17) and stable (1.18 and later) module spellings, with the algorithm constant passed to each factory reported from the call site.
