Diffie-Hellman and DSA parameter generation now reports a key size in the call graph. C DH_generate_parameters_ex, DH_generate_parameters and EVP_PKEY_CTX_set_dh_paramgen_prime_len (bits), and Python cryptography dh.generate_parameters(generator, key_size) and dsa.generate_parameters(key_size), resolve a literal or a constant (a Python module constant or a C #define) as resolved_key_length, whether the Python argument is positional or a keyword. A size held in a variable that is not a constant stays unresolved.
