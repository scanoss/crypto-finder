Python callgraph contract coverage of pyca/cryptography also includes the post-quantum ML-KEM (FIPS 203) and ML-DSA (FIPS 204) modules from cryptography 47.0.0: ML-KEM-768 and ML-KEM-1024 key generation, seed and public-key loading, encapsulation, decapsulation and key serialization, and ML-DSA-44, ML-DSA-65 and ML-DSA-87 key generation and loading, signing and verification with an optional context, external-mu signing and verification with the MLDSAMuHasher, and key serialization. Encapsulation, decapsulation, signing and verification are reported as operations.
