C callgraph contract coverage includes the OpenSSL 3.5 post-quantum algorithms through libcrypto: ML-KEM (FIPS 203) key generation, encapsulation and decapsulation, and ML-DSA (FIPS 204) and SLH-DSA (FIPS 205) key generation, signing and verification over EVP_PKEY_sign_message_init, EVP_PKEY_sign_init_ex2, their verify counterparts and the EVP_DigestSign and EVP_DigestVerify family, with key import and export through EVP_PKEY_fromdata, EVP_PKEY_todata and the key parameter getters, and the key-type getters that report an algorithm name. The algorithm name a consumer passes to EVP_PKEY_CTX_new_from_name, EVP_PKEY_Q_keygen, EVP_KEM_fetch, EVP_SIGNATURE_fetch, the raw-key importers or a signature-context initializer is reported from the call site.
