Python call arguments that name a local variable now carry its value in the call graph, so bits = 2048 followed by rsa.generate_private_key(65537, bits), or c = ec.SECP521R1() followed by ec.generate_private_key(c), reports a key length the same way a module constant or an inline curve constructor does. A local resolves only when every assignment to that name in the function gives the same integer literal or zero-argument constructor call; the position of the assignment (an if branch, a loop, a try block) does not matter. A second assignment of another value, an augmented assignment, a loop, with or except target, tuple unpacking, an assignment expression, a parameter or comprehension target of the same name, an import, a nested def or class of that name, and global, nonlocal, del or match bindings give no value. Class attributes read as self.BITS are not resolved.
