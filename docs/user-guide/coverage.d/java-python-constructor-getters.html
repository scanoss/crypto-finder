A Java or Python algorithm argument read through a getter of a field the constructor sets now carries the argument the object was constructed with, so rule conditions on the algorithm match it. This covers a getter called on the construction itself, such as new Holder("SHA256withECDSA").getAlg() or Holder("sha256").get_alg(), on a local variable bound once to the construction, and on a Java enum constant, whose getter or toString() gives the constant's argument. The class may be declared in another file or module, and the value also reaches a helper that receives the getter result as a parameter. The getter must have one return statement, returning the field itself; in Python that statement is the whole body, and the class is imported into the calling module. The value is dropped when any code other than one constructor assignment writes the field, including an initializer block, a nested, inner or anonymous class, a lambda, and a write through another reference such as h.alg = "MD5" anywhere in the declaring Java file. It is also dropped when a Java field is neither private nor final, when the local is rebound, when the constructed class overrides or inherits the getter, and when an enum constant body overrides it. A Python class gives no value when it has a base other than object, a decorator, a class attribute or property named like the field, its own __new__, __setattr__, __delattr__ or __getattribute__, or a method that passes, returns or stores self. A Python local resolves only when every use of it in the function is a direct method call: passed to a helper, aliased, returned, stored, captured by a nested function or lambda, or used in with, it gives no value. A Python @property and a direct attribute read are not resolved. A class patched from another module, such as Holder.get_alg = ..., or a field written by reflection, such as Java Field.set, still reads as the constructor's argument.
