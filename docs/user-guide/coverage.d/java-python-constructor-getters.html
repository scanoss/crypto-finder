A Java or Python algorithm argument read through a getter of a field the constructor sets now carries the argument the object was constructed with, so rule conditions on the algorithm match it. This covers a getter called on the construction itself, such as new Holder("SHA256withECDSA").getAlg() or Holder("sha256").get_alg(), on a local variable bound once to the construction, and on a Java enum constant, whose getter or toString() gives the constant's argument. The class may be declared in another file or module, and the value also reaches a helper that receives the getter result as a parameter. The getter must have one return statement, returning the field itself; in Python that statement is the whole body, and the class is imported into the calling module. The value is dropped when any code other than one constructor assignment writes the field, when a Java field is neither private nor final, when the local is rebound or has an attribute written in the same function, when the constructed class overrides or inherits the getter, and when an enum constant body overrides it. A Python @property and a direct attribute read are not resolved.
