Go and C call arguments that name a literal constant now carry its value in the call graph, so a key size written as const bits = 3072 or #define BITS 4096 is reported as resolved_value the same way a Java static final or a Python module constant is. Go resolves integer and string const declarations from the same file, at package or function scope, and a local variable or parameter of the same name hides the constant. C resolves an object-like #define from the same file that precedes the call. A function-like macro, a macro defined more than once or undefined in the file, a constant built from an expression or iota, and a constant declared in another file or header give no value.
