Go and C call arguments that name a literal constant now carry its value in the call graph, so a key size written as const bits = 3072 or #define BITS 4096 is reported as resolved_value the same way a Java static final or a Python module constant is. Go resolves integer and string const declarations (untyped, or typed as an integer or string type) from the same file, at package or function scope, and a local variable or parameter of the same name hides the constant. C resolves an object-like #define from the same file that precedes the call and sits outside any conditional block. A define under #if, #ifdef, #ifndef, #elif or #else gives no value, because the build can override or disable it; the file's own include guard is not counted as a conditional. A function-like macro, a macro defined more than once or undefined in the file, a constant built from an expression or iota, and a constant the build can bind differently give no value. A constant declared in another file or header resolves only under the rules in the cross-file entry below.
