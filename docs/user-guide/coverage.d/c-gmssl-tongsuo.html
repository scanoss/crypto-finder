C callgraph contract coverage includes GmSSL 3.x: SM2 key generation, signing, verification, encryption, decryption and key agreement, SM3 digests, HMAC, HKDF and PBKDF2, SM4 in ECB, CBC, CFB, OFB, CTR, GCM, CCM and XTS modes and its SM3-HMAC AEAD modes, ZUC encryption and MAC, SM9 signing, encryption, key encapsulation and key exchange, the generic digest and block-cipher API selected through DIGEST_sm3 and BLOCK_CIPHER_sm4, and the TLCP and TLS 1.3 context setters. It also includes the Tongsuo-only APIs: SM4-GCM and SM4-CCM, white-box SM4, ZUC EEA3, the SM3_* functions, SM2 threshold signing and decryption, the TSAPI_* and SDF wrappers, Paillier, EC-ElGamal and NTLS (TLCP).
