Node.js crypto.generateKeyPair, generateKeyPairSync, generateKey and generateKeySync (imported as crypto or node:crypto) report a key size in the call graph when the options argument is an object literal and the key type is a string literal. modulusLength (RSA, RSA-PSS, DSA), primeLength (DH) and length (AES, HMAC) are bits, and an EC namedCurve such as prime256v1, secp384r1 or P-521 resolves to the curve's field size. An options object held in a variable, a spread or computed key, a size held in a variable, an unlisted curve, and a callback written as an arrow function on the same line as the call stay unresolved.
