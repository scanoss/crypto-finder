A Python algorithm name that reaches a crypto call through a variable now resolves from the call graph. A string local, a module string constant, or a function parameter is reported with the value each caller passes, also when the caller is in another module and passes the argument by keyword, so def digest(data, alg): return hashlib.new(alg, data) called as digest(body, "sha256") is reported as SHA-256. A caller that passes a dynamic value keeps the generic finding. Method parameters (after self or cls), keyword-only parameters, parameters after *args or **kwargs, default values, f-strings and byte strings are not resolved, and a name bound more than once in its scope resolves to nothing.
