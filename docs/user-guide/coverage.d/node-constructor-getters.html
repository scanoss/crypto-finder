A JavaScript or TypeScript algorithm argument read through a getter of a field the constructor sets from a parameter now carries the argument the object was constructed with. This covers new Holder("sha256").getAlg(), a local bound once to the construction, a #private field, a class imported by name from another project module, and a helper that receives the getter result as a parameter. The getter's body must be return this.field. The value is dropped for a class that extends another, a field that another method, a field initializer or Object.assign(this, ..) writes, a class whose members the file reassigns, and a receiver local that is rebound or has a member written. It is also dropped when any code in the declaring file writes a property of that name through another reference, such as h.alg = "md5", and when the class uses this other than to reach a member, such as return this. A receiver local resolves only when every use of it in the function is a direct method call: passed to a helper, aliased, returned, stored, captured by a closure, or a method taken as a value, it gives no value. A class patched from another module still reads as the constructor's argument. A property read such as h.alg and a get accessor are not resolved.
