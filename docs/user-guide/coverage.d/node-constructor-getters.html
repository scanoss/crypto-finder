A JavaScript or TypeScript algorithm argument read through a getter of a field the constructor sets from a parameter now carries the argument the object was constructed with. This covers new Holder("sha256").getAlg(), a local bound once to the construction, a #private field, a class imported by name from another project module, and a helper that receives the getter result as a parameter. The getter's body must be return this.field. The value is dropped for a class that extends another, a field that another method, a field initializer or Object.assign(this, ..) writes, a class whose members the file reassigns, and a receiver local that is rebound or has a member written. A property read such as h.alg and a get accessor are not resolved.
