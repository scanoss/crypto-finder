Go crypto/ecdh key generation reports the curve's size when the curve is the receiver: ecdh.P256().GenerateKey(rand.Reader) and ecdh.P384().NewPrivateKey(b) report 256 and 384 bits, as does the same call on a local variable assigned once from ecdh.P521(). A curve passed in as a parameter, a variable that is reassigned, and ecdh.X25519() stay without a key length.
