A Java or Python algorithm argument that names a value declared in another file now carries that value, so rule conditions on the algorithm match it. Java resolves an enum constant's name(), and its toString() when neither the enum nor the constant overrides toString, next to the static final String constants it already resolved. A bare enum constant such as AlgoName.EC is reported as written. Python resolves a module string constant imported with from module import NAME (also with as) or read as module.NAME through import module, and a member of an Enum class: Alg.SHA.value is the member's string and Alg.SHA.name its name. A bare Alg.SHA is resolved only when the class derives from StrEnum or from str and Enum. The value is dropped when the module binds the name more than once, when the calling function binds the same name, or when the enum class has a base other than Enum, StrEnum and str. It is also dropped when any module of the project may write it at runtime: an assignment such as settings.ALG = os.environ["HASH_ALG"], an augmented assignment, del, setattr, or the module object passed, aliased or returned. An Enum member cannot be reassigned, so only a rebinding of its class drops it.
