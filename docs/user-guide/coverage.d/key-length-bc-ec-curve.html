Bouncy Castle EC key generation reports the curve's field size when the curve is named by a string literal: ECNamedCurveTable.getByName("secp256r1"), SECNamedCurves, NISTNamedCurves, TeleTrusTNamedCurves and CustomNamedCurves lookups carry it through ECDomainParameters and ECKeyGenerationParameters to ECKeyPairGenerator.init, and ECNamedCurveTable.getParameterSpec or new ECNamedCurveGenParameterSpec(..) carries it to KeyPairGenerator.initialize. A curve name that is not a known literal, or a domain assembled from lookups of different curves, stays without a key length.
