A JavaScript or TypeScript algorithm argument written as a name now carries the value the name holds, so rule conditions on the algorithm match it. This covers a string bound by a const, a never reassigned let or a var declared earlier in the same function, a module constant of the same file, an export const of another project module imported by name, as a namespace or through require (with module.exports or exports.NAME in the declaring module), a member of a string-initialized TypeScript enum or of a const bound to Object.freeze({..}) or a plain object literal, and a plain parameter whose callers in any project module all pass one of these. The value is dropped when the binding is reassigned or shadowed, for an exported let, a parameter with a default value, destructuring or rest, a mutated or escaping object, an object with a spread, computed key, method or accessor, a numeric enum member, a package or default import, a re-export from another module, a template literal with a substitution, and an argument after a spread. An exported value is also dropped when any module of the project may write it at runtime, for example config.hashAlgorithm = process.env.HASH_ALG through a require or an import, a delete, Object.assign or Object.defineProperty, or the imported object passed, aliased, returned or re-exported. A member of an Object.freeze({..}) object cannot be written, so it stays resolved.
