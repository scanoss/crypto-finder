Key length now resolves from the parameter that names it: Go dsa.GenerateParameters reports the modulus size of its dsa.L2048N256-style constant, Go ecdsa.GenerateKey(elliptic.P256(), ...) and Python ec.generate_private_key(ec.SECP384R1()) report the curve's field size, Java KeyPairGenerator.initialize(new ECGenParameterSpec("secp256r1")) agrees with its spec constructor, and Bouncy Castle RSAKeyGenerationParameters, DSAParameterGenerationParameters and the DSA, DH and ElGamal parameter generators report their strength in bits. A curve or parameter set that is not a known standard name stays without a key length.
