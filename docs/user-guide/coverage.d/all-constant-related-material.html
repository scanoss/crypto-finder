A salt, nonce or iv written as a constant is now reported. When the scan builds a call graph, a salt, nonce or iv argument of a known API that is a constant (Python bytes literals, 'text'.encode(), bytes(n), bytearray(n) and bytes.fromhex(...); JavaScript and TypeScript string literals, Buffer.alloc(n), Buffer.from('...') and new Uint8Array(n)) is reported as a related-crypto-material asset at the constant, with the crypto call's rule. The same holds when the argument is a parameter whose default value is a constant, or whose caller passes a constant, up to three calls deep. The Python hashlib.pbkdf2_hmac and hashlib.scrypt salts are now covered arguments too. A parameter that may be reassigned before the call is not followed.
