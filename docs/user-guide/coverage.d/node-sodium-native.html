JavaScript and TypeScript callgraph contract coverage includes sodium-native 2.x to 5.x: authenticated encryption (ChaCha20-Poly1305 and XChaCha20-Poly1305 IETF, secretbox, box and sealed boxes, secretstream), signatures, key exchange (kx, scalarmult), generic, SHA-256 and SHA-512 hashing, MACs (auth, onetimeauth, shorthash), password hashing and key derivation (pwhash, scrypt, kdf, PBKDF2-SHA512), stream ciphers and random bytes. The functions write into caller-supplied buffers, so most return nothing and the verify and open calls return a boolean.
