- A Java call the bytecode index repairs by the type's simple name now links only to a class the caller's artifact compiles against: its own, the project's, or a dependency's in the resolved dependency graph. The parser keys a call on a private nested class, such as `new Holder(queue)` inside ehcache's `VicariousThreadLocal`, as a same-package type no graph declares, and the index then rewrote it to the only other `Holder` it knew, BouncyCastle's `org.bouncycastle.asn1.x509.Holder`. That edge had no `entry_resolution` and made BouncyCastle findings reachable from ehcache.
