- OpenGrep scans load their rules about seven times faster. The filtered rules handed to OpenGrep are now written as JSON text, which OpenGrep parses far faster than YAML. With the JavaScript and TypeScript rules (about 1,600), each OpenGrep run spent about 17 s loading rules and now spends about 5 s. Every scan runs OpenGrep at least once, and dependency scans run it once per batch. Findings, rule IDs and metadata are unchanged. A rule file whose YAML has no JSON form with the same meaning (for example a number written `0x10`, or an alias) is still passed to OpenGrep on its own, as before.
