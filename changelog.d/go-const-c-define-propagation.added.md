- The call graph now propagates Go `const` and C object-like `#define` literals into call arguments, so `rsa.GenerateKey(rand.Reader, bits)` with `const bits = 3072`, or `EVP_PKEY_CTX_set_rsa_keygen_bits(ctx, BITS)` with `#define BITS 4096`, reports `resolved_value` `3072` or `4096` on the parameter, as Java `static final` and Python module constants already do. Go covers integer and string constants (untyped, or typed with an integer or string type) at package or function scope in the same file, and a local variable or parameter of the same name hides the constant. C covers a literal define in the same file that precedes the call and sits outside any `#if`, `#ifdef`, `#ifndef`, `#elif` or `#else` block; a define inside the file's own include guard still counts, but an `#ifndef BITS` default that `-DBITS` can override, or a define under `#if 0`, does not. A function-like macro, a name defined more than once or `#undef`'d, an expression or `iota` initializer, and a constant declared in another file give no value.
