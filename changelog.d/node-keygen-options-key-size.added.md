- Key length now resolves for Node.js `crypto.generateKeyPair`, `crypto.generateKeyPairSync`, `crypto.generateKey` and `crypto.generateKeySync` (imported as `crypto` or `node:crypto`, whole module or destructured) when the options argument is an object literal. The key type, a string literal, selects the property: `modulusLength` for `'rsa'`, `'rsa-pss'` and `'dsa'`, `primeLength` for `'dh'`, `length` for `'aes'` and `'hmac'` (all in bits), and `namedCurve` for `'ec'`, whose curve name (`'prime256v1'`, `'secp384r1'`, `'P-521'`) resolves to its field size. The value is reported as `supporting_calls[].supporting_call.resolved_key_length`. A key type or size held in a variable, an options object held in a variable or built with a spread or a computed key, a non-literal size, and a callback written as an arrow function on the same line as the call all report no key length. A new contract field, `contributes.argument_property`, names the object property a derivation reads; it is valid only in Node contracts. (#716)
