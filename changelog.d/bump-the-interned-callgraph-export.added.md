- Callgraph export schema `6.17`, the local CLI default of `--export-callgraph` (`graphfrag.CallgraphInternedSchemaVersion`), published as `schemas/callgraph-schema-6.17.json`. It declares the optional fields this release adds to the interned render: `finding_graphs[].dependency`, `analysis.paths_total`, `analysis.paths_kept`, `analysis.route_evidence` and `analysis.no_callers_only`, `root_kind` on a chain's first frame, the stitched `unresolved_reason`, and the `unresolved_reason` values `traversal_truncated`, `unresolved_dispatch` and `dependency_without_source`. The `6.15` and `6.16` schemas are unchanged, so artifacts written at those versions still validate against them. The inlined `6.14` render stays `6.14`.
