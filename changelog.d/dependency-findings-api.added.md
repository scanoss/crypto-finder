- With an API key configured, `scan --scan-dependencies` takes a dependency's findings from the SCANOSS API (`POST /v3/cryptography/reachability/component`) when the findings cache does not hold it, instead of scanning it: the findings the mining service published for that package version, as served, including the closest mined patch of the same minor version. Dependencies the API has not mined, or any API error, are scanned locally. Call chains, conditioned findings and reachability are still computed from the local sources. Each lookup sends the dependency's purl and version to the API. `--no-dependency-findings-api` scans every dependency locally.
