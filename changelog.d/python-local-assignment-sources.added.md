- The call graph now resolves a Python call argument that names a local variable, so `bits = 2048; rsa.generate_private_key(65537, bits)`, `size = 3072; dh.generate_parameters(2, size)` and `c = ec.SECP521R1(); ec.generate_private_key(c)` report `resolved_key_length` `2048`, `3072` and `521`, as Python module constants and inline curve constructors already do. A local resolves only when every binding of that name in the function is an assignment of the same integer literal or zero-argument constructor call, wherever the assignments sit. A second assignment of another value, an augmented assignment, a loop, `with` or `except` target, tuple unpacking, a walrus, a parameter or comprehension target of the same name (in the function, a nested `def` or a `lambda`), an import, a nested `def` or `class` of that name, `global`, `nonlocal`, `del` or a `match` capture gives no value, and a local never falls back to a module constant of the same name. Class attributes such as `self.BITS` are not resolved.
