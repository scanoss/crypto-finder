- Large generated source files no longer stall the call graph. Anchoring each call to its place in the syntax tree took time proportional to the number of sibling statements around it, so a file with thousands of package-level declarations or statements in one function grew quadratically. The 4 MB `ccgo_linux_amd64.go` of `modernc.org/libc` (about 130,000 calls) now parses in 6 s instead of more than 13 minutes, so a Go project that imports `modernc.org/libc` or `modernc.org/sqlite` in production code finishes its dependency call graph. The fix applies to every language: Python module-level code and JavaScript top-level code had the same quadratic cost. Occurrence keys and call anchors are unchanged.
