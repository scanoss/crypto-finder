- Go `crypto/ecdh` key generation now reports the curve's size: `ecdh.P256().GenerateKey(rand.Reader)` reports 256, `ecdh.P384()` 384 and `ecdh.P521()` 521, and so does `NewPrivateKey` on those curves. The curve is read from the receiver, either the chained call or a local variable bound once (`c := ecdh.P256(); c.GenerateKey(r)`). A curve passed in as a parameter, a variable that is reassigned or has its address taken, and `ecdh.X25519()` still report no key length. Contracts can now mark the receiver as the source of a key size with `receiver: true`. (#716)
