- Go: the methods of a gRPC service implementation are entry points (`root_kind` `framework_entry`) when the value is passed to a generated `Register<Service>Server` or grpc-gateway `Register<Service>HandlerServer` call, so crypto in an RPC method is `reachable` instead of `no_callers` even when the type does not embed `Unimplemented<Service>Server`. The value is resolved from a `&T{}` literal, `new(T)`, a constructor (`NewT()`, `pkg.NewT()`) by the types it returns or declares, a local variable, or a parameter or field typed `*T`; a value typed as the generated interface itself (a parameter `srv pb.KeysServer`) is the types that functions declaring that interface as their result build. Only the methods of the service count: the ones the generated interface declares when it is in the scanned tree, otherwise the exported methods with a gRPC signature (`(ctx context.Context, req *Req) (*Resp, error)`, or a stream parameter and `error`). Other methods of the type, other types and a value whose type cannot be resolved stay unrooted. The catalog gains the `server_registration` shape, whose `names` are patterns. A registration counts only with evidence that it is a gRPC one: the generated `<Service>Server` interface or a `*.pb.go` file of the callee's package is in the scanned tree, or the registrar argument (the first, or the second of `Register<Service>HandlerServer`) is a `*grpc.Server`, `grpc.ServiceRegistrar` or grpc-gateway `runtime.ServeMux`, by its type in the file or by the declared result of the function it comes from, or a variable of no known type that comes from a function outside the scanned tree in a file that imports `google.golang.org/grpc`, so a project function such as `httpx.RegisterHTTPServer(mux, srv)` roots nothing. Without the interface, a stream method counts only when its stream parameter is `<Service>_<Method>Server` of the registered service. Constructors found through the interface itself skip test sources, `mock`, `mocks`, `fake`, `fakes` and `testutil` directories and `NewMock*`/`NewFake*` names, and prefer the ones the application calls.
