- A function passed as a value to an API that runs it now has an edge from the function that registers it, so crypto inside the callback is reachable when its registrar is. Before, no edge led to it and its crypto read unreachable. The callback is not made an entry point: a registrar nothing reaches leaves it unreachable, and a function nothing registers or calls stays unreachable. The edge is recorded as `exact`, and only when the API is a known one at a known argument and the argument is a bare name, `module.fn` of an imported module, or `self.method` / `this.method` that resolves to a declared function. Supported APIs:
  - Python: `threading.Thread` and `multiprocessing.Process` (`target=`), `threading.Timer`, `atexit.register`, `signal.signal`, `functools.reduce`, the builtins `map`, `filter` and `sorted`/`min`/`max` (`key=`), `submit`/`map`/`apply_async` and the like on a `concurrent.futures` executor or `multiprocessing.Pool` the same function builds, and Django `migrations.RunPython` (registered from the class body, which reaches as a root that nothing calls).
  - Go: `sort.Slice`, `slices.SortFunc`, `time.AfterFunc`, `sync.Once.Do`, `errgroup.Group.Go`, `filepath.Walk` and `WalkDir`, and a few more standard calls; the argument must be a function of the package or `pkg.Func`. A handler field assigned after the struct is built (`cmd.RunE = run` on a `cobra.Command`) is now an entry point, as the `&cobra.Command{RunE: run}` form already was.
  - JavaScript and TypeScript: `setTimeout`, `setInterval`, `setImmediate`, `queueMicrotask`, `process.nextTick`, `new Promise(fn)`, Electron `ipcMain.handle`/`on`, and, matched by method name because the receiver's type is unknown (`find`, `some`, `every` and `sort` are not matched, as they are as likely a domain method as an Array one), `.map`/`.forEach`/`.filter`/`.reduce`/`.some`/`.every`/`.find`/`.flatMap`/`.sort`, `.then`/`.catch`/`.finally` and `.on`/`.once`/`.addEventListener`.

  Still unresolved, with no edge: a callback handed to a function that is not in these lists (`register(fn)`, `api.handle(path, fn)`), a call result, a lambda stored in a variable, a method value on a typed receiver in Go, a name bound in the registering function or in a function around it (a parameter, a local, a loop, `with`, comprehension or destructured variable, a nested definition, a named result), and registrations at Go package level.
