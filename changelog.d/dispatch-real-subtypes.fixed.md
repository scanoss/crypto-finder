- Java interface and abstract-class dispatch now links a call only to methods of real subtypes of the receiver's declared type. Before, a call whose target the graph could not find exactly was linked to every method with the same name and argument count under the same two-segment package root, so `TikaInputStream.get(File, Metadata)` reached `org.apache.cxf...JaxrsResponseFuture.get(long, TimeUnit)` and chained on through unrelated libraries to findings that no caller reaches. Subtypes come from the bytecode type hierarchy and from the extends and implements clauses of parsed sources, followed transitively and resolved through each file's imports. A class whose hierarchy is unknown is no longer linked by name alone, so a missing hierarchy now costs an edge instead of inventing one. Go interface dispatch links only types that declare every method of the interface; methods promoted from an embedded field are not seen. A call on a class that inherits the method links to the nearest superclass that declares it. The same subtype rule applies to class-method dispatch in Python, which reads the declared base classes, and in Node and C++, whose parsers record no base classes, so those languages no longer gain dispatch edges by name.
- An overloaded Java method is resolved by the static types of the call's arguments before any dispatch fallback. `tika.parseToString(stream)` with an `InputStream` argument links to `parseToString(InputStream)` only, not also to the `File`, `Path` and `URL` overloads. An overload whose parameter declares exactly the argument types wins; otherwise every overload that accepts them is kept, and an argument whose type the call site does not establish constrains nothing. When no overload accepts the recorded types, all same-arity overloads are kept as before.
- `--export-callgraph` now fills `call_chains[].entry_resolution` and `entry_declared_type` in the local CLI export, as schema `6.13` defines them and the stitched export already did: `exact`, `interface_dispatch`, `python_subclass_dispatch` or `name_only` for how the call arriving at each frame was resolved, and the static type a dispatch expanded. A consumer can keep the certain part of a route and discount the rest. The schema version is unchanged.
