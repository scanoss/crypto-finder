- A JavaScript or TypeScript import written with a file extension into another directory (`import { f } from "./lib/a.js"`, `from "../bootstrap.ts"`) now links the call to the function declared in that file. Before, the callee was keyed under the importing file's directory instead of the target's, so the call reached nothing and a finding in the imported file read as having no callers. Imports without an extension, `require` calls, and imports of a file in the same directory were not affected.
