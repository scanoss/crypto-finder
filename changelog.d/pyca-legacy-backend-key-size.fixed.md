- Legacy pyca `cryptography` calls that pass `backend` (required before 3.1) now report a key size: `rsa.generate_private_key(65537, 2048, default_backend())` or with `backend=`, `dsa.generate_private_key(2048, backend)`, `dsa.generate_parameters(2048, backend)` and `dh.generate_parameters(2, 2048, backend)`. Positional `dsa.generate_private_key(2048)` resolves too. For `rsa.generate_private_key`, `dsa.generate_private_key`, `dsa.generate_parameters` and `dh.generate_parameters`, the supporting call's `canonical_signature` changes from the untyped `(?, ?)` form to the typed form (`builtins.int` per parameter), so a consumer that keyed on the old string must read the new one.
