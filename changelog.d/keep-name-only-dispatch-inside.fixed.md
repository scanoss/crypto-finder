- A Java `name_only` dispatch edge now stays inside the artifacts that could hold the subtype it guesses. A class whose ancestry is only partly known is linked only when its artifact is the receiver type's artifact, is the scanned project, or depends on the receiver type's artifact in the resolved dependency graph (for an abstract-class call, either direction). Before, the two-segment namespace root was the only bound, so `WriteOutContentHandler.toString()` in `tika-core` linked to `Vector1D.toString()` in `commons-math3` and chained through POI, PDFBox, Log4j, CXF and Ehcache to BouncyCastle findings that no caller reaches. A proven subtype is linked across artifacts as before. Without a resolved dependency graph, a guess stays in the receiver type's own artifact or the project.
