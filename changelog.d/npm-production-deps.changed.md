- `--scan-dependencies` on Node projects now scans only the production dependency tree. Packages that `package-lock.json` marks as development-only, such as test runners and the packages they pull in, are no longer scanned or placed in the dependency graph, even when they are installed. Findings in them are no longer reported. `devOptional` packages and the project's own workspace packages are still scanned. The new `--include-dev-dependencies` flag restores the previous behavior.
