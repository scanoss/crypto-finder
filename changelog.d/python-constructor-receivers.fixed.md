- A Python method called on an object built by a constructor now links to that class's method in the call graph, so a finding inside it is no longer reported unreachable when its only callers reach it that way. This covers a local bound to the constructor call (`s = Scanner(cfg); s.scan(p)`) and a call made directly on it (`Scanner(cfg).scan(p)`), for a class imported from another module, re-exported by its package, or defined in the same file. A constructor annotated `-> None` no longer hides the class. The receiver is typed only from the class the call builds: a rebind to a call of unknown type, a function that shares the class's name, or a name that is no class links nothing.
