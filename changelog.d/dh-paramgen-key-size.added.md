- Diffie-Hellman and DSA parameter generation now resolves a key size through the call graph. C `DH_generate_parameters_ex`, `DH_generate_parameters` and `EVP_PKEY_CTX_set_dh_paramgen_prime_len` (prime length in bits), and Python `cryptography` `dh.generate_parameters(generator, key_size)` and `dsa.generate_parameters(key_size)`, positional or keyword, literal or constant, report `resolved_key_length` (for example 2048). The crypto rules publish DH parameter generation without a size because key agreement is outside their key-length primitives, so findings such as these previously carried none. (#716)
