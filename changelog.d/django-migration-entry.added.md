- The class body of a Django migration, a class that extends `migrations.Migration` (or `django.db.migrations.Migration`, imported or aliased) in a file under a `migrations` directory, is now an entry point, since Django's migration loader runs it. Functions it passes to `migrations.RunPython` are reached from it through the callback edge, so crypto in a migration callback no longer reads as reachable only because nothing calls it. A class named `Migration` elsewhere, or a class in a `migrations` directory that does not extend Django's `Migration`, is not an entry point. The catalog's `supertype` shape gains an optional `directory` for Python entries.
