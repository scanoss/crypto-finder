- `root_kind` on the first frame of each `call_chains` route of the live callgraph export (`graphfrag.ExportChainNode.RootKind`): `main`, `framework_entry` (a Java `@Override` of a method of a type outside the application, such as `HttpHandler.handle`, or a method with a Spring or JAX-RS request mapping, `@Scheduled`, `@EventListener` or a Kafka, RabbitMQ, JMS or SQS listener annotation), `no_callers` (application code nothing in the application calls; a graph root on a library scanned alone) or `depth_limit`.
- `analysis.paths_total` and `analysis.paths_kept` on reachable live finding graphs (`graphfrag.ExportFindingAnalysis`): how many distinct routes the call graph holds for the finding and how many its `call_chains` show. `paths_total` saturates at the largest int64.
