- `root_kind` on the first frame of each `call_chains` route of the live callgraph export (`graphfrag.ExportChainNode.RootKind`): `main`, `framework_entry` (a Java `@Override` of a method of a type outside the application, such as `HttpHandler.handle`, or a method with a Spring or JAX-RS request mapping, `@Scheduled`, `@EventListener` or a Kafka, RabbitMQ, JMS or SQS listener annotation) or `no_callers` (application code nothing in the application calls; a graph root on a library scanned alone).
