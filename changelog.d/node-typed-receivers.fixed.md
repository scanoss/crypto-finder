- The JavaScript and TypeScript call graph now types the receiver of `x.m()` from what the code declares, so a call on an object of a project class links to that class's method and crypto inside such methods no longer reads as unreachable or `no_callers`. A receiver is typed from `const x = new X()` in a function or at module level (used by functions of the same module), `new X().m()`, a parameter or variable annotation `p: X`, a class field (`h: X`, `h = new X()`, a constructor parameter property, or `this.h = new X()` in the constructor), and the declared return type of a function (`function make(): Base`, then `const t = make(); t.run()`, across modules too). X resolves through the file's named, default and namespace imports of project modules, or to a class of the same file. The edge is `exact`; a call on an abstract class whose method is declared abstract also reaches the subclasses' overrides as `interface_dispatch`, across modules.
- An imported singleton now resolves to its class: with `export const projectService = new ProjectService()` or `export default new X()` (or `export default x` for a module variable of known class) in one module, `projectService.createProject()` in a module that imports it links to `ProjectService.createProject`. Only `const` exports count.
- A TypeScript `abstract class` is now parsed: its concrete methods are declared, and an abstract class with only abstract methods is still known to the graph and to the dispatch that fans out to its subclasses.
- Left unresolved, with no edge: a receiver whose type the source does not settle, that is an interface, a type alias, a generic, a union or `any` annotation, one that is rebound (`let x = new A(); x = other()`, in the function or in a nested function), shadowed by a parameter or destructuring, typed by a class from a package outside the scanned tree, or declared twice with different classes. Also unresolved: path-alias imports (`@/service`), barrel re-exports of a singleton, `export { x }` and CommonJS `module.exports = new X()`, a `static` field, a field inherited from a base class, the return type of a method (`this.make()`) or of a function with a generic or union return type, and a typed variable used inside a callback or closure of its function.
