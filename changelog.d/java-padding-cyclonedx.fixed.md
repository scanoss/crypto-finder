- `convert` now maps the Java cipher padding names `PKCS5Padding`, `PKCS7Padding` and `NoPadding` to the CycloneDX CBOM padding values `pkcs5`, `pkcs7` and `raw`, and accepts the CycloneDX values in any letter case with surrounding whitespace. Before, `convert` failed CycloneDX 1.7 schema validation, and wrote no CBOM, for any finding that carried a Java padding name. Unrecognized values such as `ISO10126Padding` still fail strict validation.
